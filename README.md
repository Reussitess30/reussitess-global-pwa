# 🚀 Reussitess® Global PWA

Ceci est l'application Web Progressive (PWA) de Reussitess® Global, permettant un accès rapide et hors ligne à notre réseau de boutiques Amazon.

## Caractéristiques

* **Mode Hors Ligne :** Grâce au Service Worker, la page de secours est toujours disponible.
* **Installation Facile :** Peut être installée directement sur l'écran d'accueil de tout appareil (via le `manifest.json`).
* **Accès Global :** Liste de nos 42 boutiques dans 14 pays.

## Déploiement
